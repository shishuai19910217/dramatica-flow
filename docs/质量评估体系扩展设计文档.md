## 一、需求分析

### 1.1 业务背景

基于《质量评析.md》中的小说质量评判框架，结合用户反馈，需要扩展现有审计体系，覆盖：

- **六个核心评判维度**：情节、人物、设定、语言、阅读体验、类型适配
- **上下文连贯性六个层次**：时间、空间、逻辑、情绪、信息、风格

```
│  │  ┌─────────────┐  ┌─────────────┐  ┌───────────┐    │    │

│              ┌───────────────────────┐                      │
│              │     SummaryAgent      │                      │
```

### 2.2 与现有 Agent 的协作关系

| Agent | 职责 | 核心方法 | 输入 | 输出 |
|-------|------|----------|------|------|
| **ArchitectAgent** | 规划写作蓝图 | `plan_chapter()` | 章纲、世界状态 | ArchitectBlueprint |
| **WriterAgent** | 生成章节正文 | `write_chapter()` | 蓝图、节拍 | WriterOutput (正文+结算表) |
| **AuditorAgent** | 叙事质量审计 | `audit_chapter()` | 正文、蓝图、结算表 | AuditReport |
| **QualityAgent** | 综合质量评估+修订 | `evaluate_chapter()` / `revise()` | 正文、蓝图、结算表 | QualityReport / 修改后正文 |
| **SummaryAgent** | 生成章节摘要（**最后一个处理环节**） | `generate_summary()` | 修订后的正文、结算表 | 摘要文本 |
| **ReviserAgent** | 通用修订（备用） | `revise()` | 正文、问题列表 | ReviseResult |

### 2.3 优化后的 Pipeline 流程

```
原流程（存在问题）：
[写手写章] → [审计] → [修订] → [保存] → [因果链提取] → [摘要生成]
                              ↑                    ↑
                         保存太早            摘要太晚

优化后流程（推荐）：
[写手写章] → [审计] → [修订] → [质量评估+修订] → [因果链提取] → [摘要生成] → [保存]
                                   ↓                      ↓               ↓
                              修订后正文              基于修订内容    状态完整后保存
```

**关键优化点**：
1. **修订前置**：所有修订（审计修订 + 质量评估修订）都在摘要生成之前完成
2. **因果链前置**：因果链提取在摘要生成之前，确保摘要可以参考完整的因果关系
3. **摘要前置**：摘要生成在保存之前，确保最终状态包含完整的摘要信息
4. **保存后置**：保存最终稿是最后一个主要步骤，确保所有状态变更完成后再保存
5. **质量评估内置修订**：QualityAgent 内置修订功能，避免重复调用单独的 ReviserAgent

### 2.4 设计模式

| 模式 | 应用场景 |
|------|----------|
| **策略模式** | 不同类型使用不同的评估策略 |
| **模板方法模式** | 统一评估流程框架 |
| **工厂模式** | 根据类型创建对应的评估器 |
| **观察者模式** | 评估结果通知机制 |

## 三、六个核心评判维度扩展设计

### 3.1 情节维度

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 权重 |
|--------|----------|----------|----------|------|
| **开篇冲突** | 分析第一章前3段，检测是否建立核心冲突 | 章节正文 | 是否在三段内建立核心冲突 | 25% |
| **因果链条** | 提取事件因果关系，验证完整性 | 因果链日志 | 每个事件有明确前因后果 | 30% |
| **节奏张弛** | 统计章节类型分布，检测是否有张弛变化 | 章节元数据 | 避免连续重复章节类型 | 25% |
| **结局呼应** | 对比首尾内容，检查是否呼应开篇钩子 | 章节正文 | 结局是否回应开篇承诺 | 20% |

### 3.2 人物维度

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 权重 |
|--------|----------|----------|----------|------|
| **主角欲望与缺陷** | 分析主角描述，检测是否有明确欲望和缺陷 | 人设文件+章节正文 | 欲望明确、缺陷明显 | 30% |
| **配角独立性** | 分析配角出场频次和行动描述 | 章节正文 | 独立名字+独立动机+独立行动 | 35% |
| **反派逻辑** | 分析反派行为动机 | 章节正文 | 动机合理、行为可解释 | 20% |
| **人物弧光** | 追踪角色成长轨迹 | 情感弧线日志 | 有明显成长变化 | 15% |

### 3.3 设定维度

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 权重 |
|--------|----------|----------|----------|------|
| **设定新意** | 与常见设定库对比，计算独特性评分 | 设定库+正文 | 独特性得分 ≥ 70分 | 25% |
| **逻辑自洽** | 检查规则一致性，检测冲突 | 真相文件 | 无规则冲突 | 35% |
| **规则与代价** | 分析能力使用记录，检测代价描述 | 结算表+正文 | 能力使用有规则限制和代价 | 25% |
| **服务故事** | 分析设定与剧情关联 | 章节正文 | 设定推动剧情发展 | 15% |

### 3.4 语言维度

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 权重 |
|--------|----------|----------|----------|------|
| **视觉描写丰富度** | 统计视觉词汇密度 | 章节正文 | 密度 ≥ 5% | 30% |
| **感官细节密度** | 统计五感描写频次 | 章节正文 | 每千字 ≥ 3处 | 30% |
| **比喻新颖度** | 与常见比喻库对比 | 比喻库+正文 | 新颖度得分 ≥ 60分 | 25% |
| **句式变化** | 分析句子结构多样性 | 章节正文 | 句式类型 ≥ 5种 | 15% |

### 3.5 阅读体验维度

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 权重 |
|--------|----------|----------|----------|------|
| **结尾钩子强度** | LLM评估悬念吸引力 | 章节结尾 | 吸引力评分 ≥ 70分 | 35% |
| **信息密度** | 计算信息熵 | 章节正文 | 信息熵适中 | 25% |
| **悬念设置** | 统计钩子数量和分布 | 钩子日志 | 每章 ≥ 1个有效钩子 | 25% |
| **情感共鸣** | 分析情感词频 | 章节正文 | 情感波动合理 | 15% |

### 3.6 类型适配维度

**类型特征矩阵**：

| 类型 | 核心检查项 | 权重配置 |
|------|-----------|----------|
| **悬疑/推理** | 逻辑严密性(40%)、线索埋设(30%)、结局合理性(30%) | 高 |
| **言情** | 情感真实性(40%)、人物关系张力(35%)、甜虐节奏(25%) | 高 |
| **科幻/奇幻** | 世界观完整性(40%)、设定创新性(30%)、设定与剧情结合(30%) | 高 |
| **恐怖** | 氛围营造(40%)、心理压迫感(35%)、留白技巧(25%) | 高 |
| **网文** | 开篇钩子(40%)、爽点密度(30%)、追读欲望(30%) | 高 |

## 四、上下文连贯性六个层次设计

### 4.1 时间连贯性

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 严重级别 |
|--------|----------|----------|----------|----------|

### 4.2 空间连贯性

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 严重级别 |
|--------|----------|----------|----------|----------|
| **移动交代** | 检查角色移动描述 | 章节正文 | 有起点、路径、终点 | critical |
| **场景切换过渡** | 检测场景切换 | 章节正文 | 有过渡交代 | warning |
| **空间关系合理** | 检查空间逻辑 | 章节正文 | 距离与时间匹配 | warning |

### 4.3 逻辑连贯性

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 严重级别 |
|--------|----------|----------|----------|----------|
| **因果完整性** | 验证事件因果关系 | 因果链日志 | 每个事件有前因后果 | critical |
| **动机合理性** | 分析角色决定 | 章节正文 | 有合理动机支撑 | critical |
| **规则一致性** | 检查设定规则 | 真相文件 | 规则保持一致 | critical |
| **能力成长过程** | 追踪能力变化 | 结算表 | 有过程和代价 | warning |

### 4.4 情绪连贯性

| 检查项 | 检查逻辑 | 数据来源 | 评判标准 | 严重级别 |
|--------|----------|----------|----------|----------|
| **情绪反应匹配** | 分析情绪与事件匹配度 | 章节正文 | 情绪与事件严重程度匹配 | critical |
| **情绪转变过渡** | 检测情绪转变 | 章节正文 | 有过渡和铺垫 | warning |


### 4.5 信息连贯性

### 4.6 风格连贯性

## 五、数据结构定义

### 5.1 评估结果结构

```python
from dataclasses import dataclass, field
from typing import Literal, Optional, List, Dict
from datetime import datetime

@dataclass
class QualityIssue:
    severity: Literal["critical", "warning", "info"]
    description: str
    location: Optional[str] = None
    suggestion: Optional[str] = None
    excerpt: Optional[str] = None

@dataclass
class DimensionScore:
    dimension: str
    score: int  # 0-100
    max_score: int = 100
    issues: List[QualityIssue] = field(default_factory=list)
    weight: float = 1.0

@dataclass
class QualityReport:
    chapter_number: int
    overall_score: int
    dimension_scores: List[DimensionScore]
    consistency_scores: List[DimensionScore]
    genre: str
    genre_fit_score: int
    improvement_suggestions: List[str] = field(default_factory=list)
    timestamp: str = field(default_factory=lambda: datetime.now().isoformat())

@dataclass
class GenreCriteria:
    genre: str
    criteria: List[str]
    weights: Dict[str, float]

@dataclass
class QualityReviseResult:
    """质量评估修订结果（参考 ReviseResult）"""
    content: str
    change_log: List[str]
    revised_issues: List[str]  # 已修复的问题列表
```

## 六、QualityAgent 接口设计

### 6.1 QualityAgent 主接口

```python
from typing import Optional, List, Dict, Literal
from .llm import LLMProvider
from .types.narrative import ArchitectBlueprint, PostWriteSettlement
from .agents import AuditReport, AuditIssue

class QualityAgent:
    """
    质量评估 Agent（内置修订功能）
    
    职责：
        1. 对章节进行全面的质量评估（六个核心维度 + 六大连贯性层次）
        2. 根据评估结果自动修订内容（参考 ReviserAgent）
    
    与其他 Agent 的协作关系：
        - AuditorAgent：专注叙事质量审计（深度分析，输出问题列表）
        - QualityAgent：专注综合质量评估 + 修订（输出质量分数 + 修订后内容）
        - SummaryAgent：基于修订后的最终内容生成摘要（**最后一个处理环节**）
    
    架构一致性：遵循现有 Agent 模式（ArchitectAgent/WriterAgent/AuditorAgent）
    """
    
    # 修订模式（参考 ReviserAgent）
    ReviseMode = Literal["spot-fix", "rewrite-section", "polish"]
    
    # 六大核心评判维度
    DIMENSIONS = ["情节", "人物", "设定", "语言", "阅读体验", "类型适配"]
    
    # 六大连贯性层次
    CONSISTENCY_LEVELS = ["时间", "空间", "逻辑", "情绪", "信息", "风格"]
    
    # 最大修订轮数（防止无限循环）
    MAX_REVISE_ROUNDS = 2
    
    def __init__(self, llm: LLMProvider):
        """
        初始化质量评估 Agent
        
        Args:
            llm: LLM 提供者（建议传入 temperature=0 的实例确保评分客观）
        """
        self.llm = llm
    
    def evaluate_chapter(
        self,
        chapter_content: str,
        chapter_number: int,
        genre: str,
        blueprint: ArchitectBlueprint,
        truth_context: str,
        settlement: PostWriteSettlement,
        prev_chapter_content: str = "",
        cross_thread_context: str = "",
        audit_report: Optional[AuditReport] = None,
        auto_revise: bool = True,  # 新增：是否自动修订
    ) -> tuple[str, QualityReport]:
        """
        执行章节质量评估（借鉴 AuditorAgent.audit_chapter() 参数设计）
        
        Args:
            chapter_content: 章节正文
            chapter_number: 章节编号
            genre: 小说类型（悬疑/言情/科幻/恐怖/网文）
            blueprint: 建筑师蓝图（评估参照标准）
            truth_context: 真相文件上下文（设定/人物一致性）
            settlement: 写后结算表（状态变化合理性检查）
            prev_chapter_content: 上一章内容（连贯性检查）
            cross_thread_context: 跨线程上下文（多线叙事一致性）
            audit_report: 审计报告（可复用结果，避免重复分析）
            auto_revise: 是否自动根据评估结果进行修订
        
        Returns:
            Tuple[str, QualityReport]: (修订后的正文, 质量评估报告)
        
        执行流程：
            1. 执行六个核心维度评估
            2. 执行六大连贯性层次检查
            3. 计算类型适配得分
            4. 计算综合评分
            5. 如果 auto_revise=True 且评估未通过，执行修订
            6. 返回修订后的正文和评估报告
        """
        # 1. 执行六个核心维度评估
        dimension_scores = self._evaluate_dimensions(
            chapter_content=chapter_content,
            chapter_number=chapter_number,
            genre=genre,
            blueprint=blueprint,
            truth_context=truth_context,
            settlement=settlement,
            audit_report=audit_report,
        )
        
        # 2. 执行六大连贯性层次检查
        consistency_scores = self._check_consistency(
            chapter_content=chapter_content,
            prev_chapter_content=prev_chapter_content,
            truth_context=truth_context,
            settlement=settlement,
        )
        
        # 3. 计算类型适配得分
        genre_fit_score = self._evaluate_genre_fit(
            chapter_content=chapter_content,
            genre=genre,
        )
        
        # 4. 计算综合评分
        overall_score = self._calculate_overall_score(
            dimension_scores=dimension_scores,
            consistency_scores=consistency_scores,
            genre_fit_score=genre_fit_score,
        )
        
        # 5. 生成改进建议
        improvement_suggestions = self._generate_suggestions(
            dimension_scores=dimension_scores,
            consistency_scores=consistency_scores,
            genre_fit_score=genre_fit_score,
        )
        
        # 6. 构建质量报告
        quality_report = QualityReport(
            chapter_number=chapter_number,
            overall_score=overall_score,
            dimension_scores=dimension_scores,
            consistency_scores=consistency_scores,
            genre=genre,
            genre_fit_score=genre_fit_score,
            improvement_suggestions=improvement_suggestions,
        )
        
        # 7. 自动修订（如果启用）
        final_content = chapter_content
        if auto_revise and not self._is_passed(quality_report):
            revise_result = self.revise(
                content=chapter_content,
                quality_report=quality_report,
                mode="spot-fix",
            )
            final_content = revise_result.content
        
        return final_content, quality_report
    
    def revise(
        self,
        content: str,
        quality_report: QualityReport,
        mode: ReviseMode = "spot-fix",
    ) -> QualityReviseResult:
        """
        根据质量评估报告修订内容（参考 ReviserAgent.revise()）
        
        Args:
            content: 待修订的正文
            quality_report: 质量评估报告
            mode: 修订模式
                - spot-fix: 只修改有问题的句子/段落，其余正文一字不动
                - rewrite-section: 重写包含问题的段落
                - polish: 在不改变情节的前提下提升文笔流畅度
        
        Returns:
            QualityReviseResult: 修订结果
        
        修订规则（参考 ReviserAgent）：
            - 硬约束：不得引入新情节，不得修改角色名，不得改变情节走向
            - 根据严重级别优先修复 critical 问题
            - 每个问题都有对应的修复建议
        """
        # 提取需要修复的问题（优先处理 critical）
        issues = []
        for dim_score in quality_report.dimension_scores:
            for issue in dim_score.issues:
                if issue.severity in ["critical", "warning"]:
                    issues.append(issue)
        
        for cons_score in quality_report.consistency_scores:
            for issue in cons_score.issues:
                if issue.severity in ["critical", "warning"]:
                    issues.append(issue)
        
        # 按严重级别排序（critical 优先）
        issues.sort(key=lambda x: 0 if x.severity == "critical" else 1)
        
        # 构建修订提示词
        prompt = self._build_revise_prompt(content, issues, mode)
        
        # 调用 LLM 进行修订
        resp = self.llm.complete([
            LLMMessage("system", self._get_revise_system_prompt(mode)),
            LLMMessage("user", prompt),
        ])
        
        # 解析修订结果
        result = self._parse_revise_result(resp.content)
        
        return QualityReviseResult(
            content=result["content"],
            change_log=result["change_log"],
            revised_issues=result["revised_issues"],
        )
    
    def _build_revise_prompt(
        self,
        content: str,
        issues: List[QualityIssue],
        mode: ReviseMode,
    ) -> str:
        """构建修订提示词"""
        issue_lines = []
        for i, issue in enumerate(issues):
            line = f"{i+1}. [{issue.severity.upper()}] {issue.description}"
            if issue.location:
                line += f"\n   位置：{issue.location}"
            if issue.suggestion:
                line += f"\n   建议：{issue.suggestion}"
            issue_lines.append(line)
        
        mode_instructions = {
            "spot-fix": "只修改有问题的句子/段落，其余正文一字不动",
            "rewrite-section": "重写包含问题的段落（前后各保留一段作为锚点），保持整体情节不变",
            "polish": "在不改变情节的前提下提升文笔流畅度，禁止增删段落",
        }
        
        return f"""\
## 修订任务
模式：{mode}
规则：{mode_instructions[mode]}
硬约束：不得引入新情节，不得修改角色名，不得改变情节走向。

## 需修订的问题
{chr(10).join(issue_lines)}

## 原文
{content}

---
直接输出修订后的完整正文（不要任何前言），然后输出：
{chr(10)}
["改动说明1", "改动说明2", ...]"""
    
    def _get_revise_system_prompt(self, mode: ReviseMode) -> str:
        """获取修订系统提示词"""
        return f"你是精准的小说修订者，模式：{mode}。直接输出修订后正文，不要任何前言。"
    
    def _parse_revise_result(self, response: str) -> dict:
        """解析修订结果"""
        parts = response.split("\n\n", 1)
        content = parts[0].strip()
        change_log = []
        revised_issues = []
        
        if len(parts) > 1:
            try:
                change_log = eval(parts[1].strip())
            except Exception:
                change_log = [parts[1].strip()[:200]]
        
        return {
            "content": content,
            "change_log": change_log,
            "revised_issues": revised_issues,
        }
    
    def _is_passed(self, quality_report: QualityReport) -> bool:
        """判断评估是否通过（无 critical 问题）"""
        for dim_score in quality_report.dimension_scores:
            for issue in dim_score.issues:
                if issue.severity == "critical":
                    return False
        for cons_score in quality_report.consistency_scores:
            for issue in cons_score.issues:
                if issue.severity == "critical":
                    return False
        return True
    
    def _evaluate_dimensions(self, ...) -> List[DimensionScore]: ...
    def _check_consistency(self, ...) -> List[DimensionScore]: ...
    def _evaluate_genre_fit(self, ...) -> int: ...
    def _calculate_overall_score(self, ...) -> int: ...
    def _generate_suggestions(self, ...) -> List[str]: ...
```

3. **确保状态完整**：摘要生成后立即保存，确保状态一致性
4. **避免重复工作**：所有修订完成后才生成摘要，避免重复生成
