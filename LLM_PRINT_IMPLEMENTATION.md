
# LLM 提示词打印功能实现说明

## 概述
已成功实现 LLM 调用前自动打印完整提示词的功能。

## 实现方案

### 修改文件
- **文件:** `core/llm/__init__.py`

### 新增功能

1. **新增工具函数 `_print_llm_prompt()`
   - 格式化打印所有提示词内容
   - 显示配置信息（Model, Temperature, Max Tokens, Stream status）
   - 区分 SYSTEM/USER/ASSISTANT 消息
   - 使用分隔线提高可读性

2. **修改 `DeepSeekProvider.complete()`**
   - 调用前自动打印提示词

3. **修改 `DeepSeekProvider.stream()`**
   - 调用前自动打印提示词

4. **修改 `OllamaProvider.complete()`**
   - 调用前自动打印提示词

5. **修改 `OllamaProvider.stream()`**
   - 调用前自动打印提示词

## 输出格式示例

```
================================================================================
LLM Prompt:
================================================================================

[Configuration]
  Model: deepseek-chat
  Temperature: 0.7
  Stream: No

--------------------------------------------------------------------------------

[SYSTEM Message 1]
--------------------------------------------------------------------------------
你是故事建筑师，只输出合法JSON。

[USER Message 2]
--------------------------------------------------------------------------------
请生成故事大纲...

================================================================================
End of LLM Prompt
================================================================================
```

## 特性

- **不影响正常流程：打印操作在实际调用前执行
- **性能影响小**：只是简单的打印操作
- **标识清晰**：有明确的 "LLM Prompt:" 标签
- **完整信息**：包含配置和所有消息内容
- **统一覆盖**：无论是 Agents、Narrative、Server 等所有调用点
